Supreme Diffusion — Help

A desktop application for AI video generation, image creation, lip sync, and non-linear video editing.

v3.1.0 — GL-rendered Quick Export (pixel-identical to timeline preview), multi-clip batch Quick Export, "Use Post Processing?" prompt, Combine preserves resolution + per-clip effects. Plus everything from 3.0: Batch Generate, Sequential Processing, Create Loop, app-wide yuvj420p colour fix. Bug reports welcome.

Supported Models

  • Wan 2.2 I2V 14B — Image-to-Video generation (standard quality)
  • Wan 2.2 I2V 14B Lightning v2 — Image-to-Video generation (fast, distilled)
  • Stable Diffusion 1.5 / SDXL — Image generation (txt2img, img2img, inpaint)
  • TripoSR — Single-image 3D mesh generation with animation timeline

In Development: FLUX image generation and Z-Image Turbo are partially implemented but not yet fully tested. Expect issues with these features.

1. Getting Started

Launch

The start script handles everything — just clone and run:

git clone https://github.com/saintorphan/SupremeDiffusion.git
cd SupremeDiffusion
./start.sh          # Linux / macOS
start.bat           # Windows

What the start script does

On first run:

  1. Checks for FFmpeg and offers to install it via your package manager if missing
  2. Creates a .venv/ Python virtual environment
  3. Installs PyTorch with CUDA 12.4 support (if not already installed)
  4. Installs all Python dependencies: PySide6, diffusers, transformers, accelerate, peft, safetensors, optimum-quanto, gguf, mmgp, xformers, Pillow, numpy, opencv-python, etc.
  5. Prompts you to install optional components per-feature: face swap, 3D modeling, LoRA training, Chatterbox TTS, Dia TTS, AudioCraft — answer Y or N for each
  6. Creates factory directories for models, projects, and libraries
  7. Launches the application

On every subsequent run:

  1. Checks GitHub for updates and pulls them automatically (fast-forward only)
  2. Re-installs dependencies if the update changed them
  3. Launches the application
If you need a different CUDA version (e.g. 11.8 or 12.1), install PyTorch manually into the .venv/ before running the start script — it will detect the existing install and skip that step.

First-Time Setup

  1. Model paths default to factory directories inside the app folder (models/checkpoints/, models/vae/, etc.). Drop your model files into these folders, or point the Settings paths to existing directories on your system.
  2. Models download automatically — when you click Generate for the first time, the app checks if the required models are present. If not, it prompts you to download them from Hugging Face. The right quantization variant is selected automatically based on your VRAM.
  3. Under Performance, choose your Denoising Loop:
    • standard — default diffusers loop, widest compatibility.
    • wan2gp — optimized loop with NAG, TEA Cache, Quality controls, and multi-phase generation. Requires more VRAM but unlocks advanced features.

Hardware Requirements

This application's inference orchestrator was developed, tested, and optimized on a Linux PC with an NVIDIA RTX 3080 Ti (12 GB VRAM) and 32 GB DDR4 RAM.

With the settings below, it successfully runs both Wan 2.2 I2V 14B and Wan 2.2 I2V 14B Lightning v2 at 480P (512×512, 832×480, 480×832):

SettingValueWhy
Transformer quantizationint8~14.5 GB model compressed to fit in 12 GB VRAM
Text encoder quantizationint8Reduces text encoder memory footprint
Attention modexformersMemory-efficient attention — critical for 12 GB cards
Memory profile4 (aggressive)Maximum offloading between pipeline stages
Boost2MMGP memory management optimizations
VAE tilingAutoTiles VAE decode to avoid VRAM spikes
Mixed precisionEnabledfp16 compute where possible

Lightning v2 generates a 5-second 480P video in ~4 steps. Standard Wan 2.2 I2V 14B uses ~20–30 steps for higher quality. Both use the same ~14.5 GB int8-quantized transformer weights.

Generated 480P videos can then be post-processed in a single pass: RIFE x2 doubles the frame rate (16 fps → 32 fps) for smoother motion, and Lanczos spatial upscale doubles the resolution to 1024×1024 (or 1664×960 / 960×1664 for landscape/portrait). Both are available as checkboxes in the generation parameters — no external tools needed.

An NVIDIA GPU with CUDA support is required. The app auto-detects your VRAM tier and selects the appropriate quantized model variant. Cards with 8–12 GB run int8; 24 GB+ can run unquantized bf16.

Creating Your First Project

  1. In the header banner at the top, click the + button next to the project dropdown.
  2. Enter a project name and choose a resolution preset.
  3. All generated outputs (videos, images, faces, frames) are saved under this project.
  4. Switch projects at any time with the dropdown — your workspace state is preserved.

Basic Workflow: Image-to-Video

  1. Go to Video > Img2Vid.
  2. Mode 1 is selected by default. Drop or browse for a source image.
  3. Type a prompt describing the desired motion (e.g. a woman smiles and turns her head slowly).
  4. Click Generate (or press Ctrl+G).
  5. Preview plays automatically when done. Right-click the preview to send the clip to other tabs (Timeline, Video Extender, Trim, etc.).

Prompt Enhancement & AI Assistant (Qwen 3.5 4B)

All image and video generation tabs show Qwen 4B Enhance: followed by a style dropdown, Enhance POS, and Enhance NEG buttons. These use a local Qwen 3.5 4B LLM (BF16, ~5 GB) to rewrite your prompt in the correct syntax for your chosen model family, or generate a matching negative prompt.

The same model powers the AI Assistant chat window (click the AI button in the header bar). See AI Assistant for details.

  • The model downloads automatically on first use (~5 GB from Hugging Face).
  • Inference runs on your GPU via transformers — no internet needed after download.
  • Active pipelines are unloaded to free VRAM before the LLM loads. The model stays loaded for reuse across multiple enhances.
  • Starting any generation pipeline (video, image, etc.) automatically unloads Qwen to reclaim VRAM.

Supported Model Prompt Styles

StylePositive Prompt FormatNegative Prompt Format
SD 1.5 Danbooru-style comma-separated tags with masterpiece, best quality, highly detailed prefix. Standard quality/artifact avoidance tags (worst quality, bad anatomy, blurry).
SDXL Flowing natural language (2–3 sentences). Composition, lighting, atmosphere, quality modifiers. Natural negative terms for artifacts and low quality.
SD3 / SD3.5 Longer natural language (3–4 sentences). T5 encoder understands full prose — no booru tags needed. Describes subject, scene, lighting, color palette, artistic style. Plain English sentences (not comma-separated tags).
FLUX Rich descriptive paragraph (4–6 sentences). Vivid prose describing subject, environment, mood, camera angle, color grading. No tags, no quality prefixes — just write naturally. FLUX does not use negative prompts. The LLM will advise you to improve the positive prompt instead.
Pony: Real Score tags (score_9, score_8_up, score_7_up) + photorealistic descriptors (realistic, photo, detailed skin, natural lighting). Avoids anime/cartoon tags. Score negatives + excludes anime, cartoon, illustration, painting, drawing.
Pony: Anime Score tags + anime/booru-style tags (1girl, anime coloring, detailed eyes, cel shading). Score negatives + excludes realistic, photo, 3d render.
Illustrious Quality prefix (masterpiece, best quality, absurdres) + detailed booru-style descriptors. Standard booru negative tags (worst quality, lowres, bad anatomy).
NoobAI NoobAI quality hierarchy (masterpiece, best quality, amazing quality, very aesthetic, absurdres) + detailed danbooru tags. Variant of Illustrious with its own quality tier system. NoobAI-specific quality negatives (worst quality, bad quality, low quality, normal quality).
Tip: Select the style that matches your checkpoint. Using the wrong style (e.g. booru tags on FLUX, or natural language on SD 1.5) will produce poor results. When in doubt, try SDXL for realistic models or Illustrious for anime models.

4. Send-To System

Supreme Diffusion uses a right-click context menu system for routing media between tabs:

On any video player (right-click):

  • Send clip to — Timeline, Img2Vid, Video Extender, Longshot, Trim, Crop.
  • Send frame to — Captures the current playhead frame and sends it to any Image tab (All2Img, Inpaint, Draw, Face Swap, Body Double, RePose, ControlNet, 3D Modeling, Crop/Zoom).
  • Send as final frame — Load the frame as the destination frame for Img2Vid Mode 2 or Video Extender.
  • Send as guide video — Generate a 5-second still clip and load it as guidance video.

On image galleries (right-click):

  • Send to — All2Img, Inpaint, Draw, Face Swap, Img2Vid, Body Double, RePose, ControlNet, 3D Modeling, Crop/Zoom.
  • Generation settings (prompt, sampler, scheduler) transfer along with the image.

On source image widgets (right-click):

  • Same send-to targets as galleries, plus Final Frame and Guide Video options.

"Save as 3D Model" buttons:

  • Available on image generation tabs.
  • Generates a 3D mesh from the selected gallery image via TripoSR.
  • Mesh is saved to project/meshes/ and appears in the 3D Modeling tab inventory.

On audio outputs and audio player (right-click):

  • Send to — Other audio tabs (Chatterbox, Dia, MusicGen, AudioGen), Voice Library, Sound Library.
  • Save to Voice Library — Copy the audio to the global Voice Library for cross-project reuse.

5. Timeline

Multi-track timeline for assembling clips into sequences.

Layout

  • Clip Library (left sidebar) — Browse project clips, drag onto tracks.
  • Multitrack Canvas (center) — Arrange clips on parallel video/audio tracks.
  • Preview Player (right) — Playback the assembled sequence.
  • Transport Controls (bottom) — Play, pause, scrub, timeline ruler.

Workflow

  1. Generate clips in the Video tab (Img2Vid, Video Extender, or Longshot sub-tabs).
  2. Clips appear in the Clip Library automatically.
  3. Drag clips from the library onto a track.
  4. Reorder, trim, and layer clips across multiple tracks.
  5. Right-click clips for effects, speed, lip sync, rotate, and more.
  6. Export the final assembled video via the Export dialog.

Clip Context Menu (right-click)

  • Effects — Add per-clip effects from 5 categories (Color, Filter, Transform, Enhance, Encode). See Timeline Effects.
  • Match Grade → / ← — Generate a 3D LUT from this clip and apply it to all clips to the right (or left) so they colour-match. "Match All To" grades every clip on every track to this one; "Match Similar Clips" grades all clips sharing this one's name. "Chain" mode advances the reference clip-by-clip so gradual look changes carry through.
  • Lip Sync (MuseTalk)... — Opens the MuseTalk dialog to lip-sync audio to the clip's face.
  • Rotate 90 CW / CCW — Rotate the clip 90 degrees.
  • Speed — 0.1x–4.0x with presets.
  • Reverse — Reverse the clip playback direction.
  • Create Loop... — Opens the Create Loop dialog. Builds a seamless forward+reverse loop from the clip via a single ffmpeg filter_complex pass (no codec drift between halves), trims any black frames at the seam, previews inline, and lets you Save to <project>/clips/<name>_loop.mp4 or Export/Quick Export directly.
  • Export... — Opens the standard export dialog pre-configured for a single-clip export.
  • Quick Export... — Asks "Use Post Processing?" (Yes/No/Cancel):
    • Yes captures the clip through the GL shader pipeline (pixel-identical to the timeline preview — LUTs, colour correction, all effects rendered by the same OpenGL path you see on screen), then chains denoise + sharpen + face restore + lanczos 1.5x + RIFE 2x on top of the GL-rendered result.
    • No captures via GL only — pure WYSIWYG, no AI pipeline. Use this when the source clip has already been post-processed and you just want the timeline looks baked in without compounding upscale/framerate/sharpening.
    When invoked from a non-timeline context (Browser, Clip Library, video preview), the GL path is unavailable and Quick Export falls back to the ffmpeg FULL_RANGE_FILTER + lut3d bake path instead.

Multi-Clip Context Menu (shift-click / rubber-band)

  • Combine — Merge selected clips into a single clip. Preserves the first clip's native resolution (no forced 1280×720 letterboxing) and bakes each clip's individual effect stack (LUTs, colour correction, etc.) into its segment of the combined output.
  • Close Gaps — Butt selected clips up against each other.
  • Effects » Paste / Clear / Bake — Apply clipboard effect stack, clear all effects, or bake effects into new files — across every selected clip at once.
  • Quick Export N clips... — Pick an output folder, answer the Post Process prompt once, and batch-export every selected clip sequentially. One unified progress dialog tracks the whole batch; Cancel aborts cleanly. Each output file is named after the clip and auto-suffixed on collision.
  • Remove N clips — Delete all selected clips from the timeline.

Drag & Drop (multi-file)

Dragging multiple files from a file manager onto the Multitrack canvas lays them down end-to-end sequentially in drop order starting at the drop position. Each clip's duration is probed on drop so the next one butts right up against its end.

DAW-Style Zoom Scrollbar

The timeline features a DAW-style zoom scrollbar at the bottom. Drag the edges to zoom in/out, drag the center to scroll. Also supports Ctrl+Scroll to zoom at the cursor position.

Tip: GL Render export produces pixel-identical output to the preview. All color effects, compositing, and blending are rendered through the same OpenGL shaders you see in real-time. Full-range color preservation (in_range=full:out_range=full) is applied automatically on all encodes.
v3.0 colour fix: Every ffmpeg encode in the app now outputs via -pix_fmt yuvj420p instead of the old -pix_fmt yuv420p -color_range pc combo. libx264 silently squeezes full-range RGB into TV-range Y[16,235] unless the output pix_fmt is explicitly yuvj420p — so the old convention shipped files where black pixels ended up at RGB 16 (grey) instead of 0. If your earlier exports looked washed out compared to the timeline preview, this is why. The fix was swept across 17 call sites including Quick Export, Batch, Sequential, Timeline Export, Bake Effects, Color Correct, Loop Build, Trim, Crop, Speed, MuseTalk, LatentSync, Video Retalking, and render3d.

6. Generate (Img2Vid)

Create videos from images using Wan 2.1/2.2 diffusion models. Three generation modes:

Mode 1 — Single Image

Drop a source image. The model animates it based on your prompt.

Mode 2 — First + Last Frame

Provide a first frame and a last frame. The model interpolates between them. Optionally add a final frame (destination) and/or guidance video.

Mode 3 — Video Clip

Provide an existing video clip. The model re-renders it with the prompt applied (video-to-video style transfer).

Controls

ControlDescription
PromptDescribe the desired motion and scene content.
Negative PromptDescribe what to avoid (e.g. blurry, static, deformed).
GenerateStart video generation.
Batch Generate / Sequential ProcessingMode-conditional button next to Generate. Mode 1 shows Batch Generate, Mode 2 shows Sequential Processing, Mode 3 hides it. See below.
AbortCancel in-progress generation (works for single, batch, and sequential runs).
Save ClipSave the preview to the project with a custom name.

Batch Generate (Mode 1 only)

Opens a dialog to run img2vid over a folder or multi-file selection of source images with the current tab's prompt + settings applied to each one in turn.

  • Source — Radio: Input Directory or Input Files. Files are picked in drop order.
  • Output Directory — Where the generated clips are written.
  • Clip File Prefix — Each output is named <prefix><NNN>.mp4 with zero-padded indexing.
  • Continue from last number in directory — Scans the output dir for existing <prefix><digits>.mp4 files and starts numbering one past the highest, so you can resume a batch without overwriting.
  • Generate / Use guidance vid — Auto-synthesise a static guidance video from each source image and pass it to the img2vid pipeline.
  • Color Correct (match against reference) — Tick + pick a reference image or video. Every generated clip gets a 3D LUT made from the reference (same generate_lut3d helper the timeline Match Grade uses) and the LUT applied.
  • Create Loops — Run each generated clip through the Loop Builder before saving.
  • Apply Post-Process — Tick to reveal the full post-process controls (denoise, sharpen, upscale, face restore, tile size, lanczos, film grain). Same UI as the Export dialog.

All dialog fields persist across launches via GlobalConfig.batch_generate_settings. The Abort button stops the current item cleanly and exits the batch; errors on individual items are logged and skipped without stopping the whole run.

Sequential Processing (Mode 2 only)

Pair-based img2vid over a numerically-named image sequence. For files 0.png, 1.png, 2.png, ... (any contiguous integer run, can start at any index) the processor iterates sliding pairs (0,1), (1,2), (2,3), ... and generates a Mode 2 first-frame/last-frame video for each pair.

  • Strict validation — Every file stem must be a bare integer, and the full set must be contiguous. A gap like [0,1,2,4] errors before starting.
  • Guidance Frame: First / Last — Extra dropdown next to the guidance checkbox. Picks which of the pair's two frames is used to build the static guidance tensor.
  • Output filename — <prefix><first>_<last>.mp4 zero-padded to the width of the highest integer in the batch. For pairs (0,1), (1,2), (2,3) with prefix anim_ you get anim_000_001.mp4 / anim_001_002.mp4 / anim_002_003.mp4.
  • Shared pipeline — Same Color Correct, Post-Process, error-skip, and Abort behaviour as Batch Generate. "Create Loops" is deliberately hidden for sequential runs.

See Appendix: Generation Parameters Reference for full details on all shared generation settings (steps, guidance, LoRA, post-processing, etc.).

8. Longshot

Create long-form videos by splitting a source clip into chunks, rendering gapfill transitions between them, then assembling the final output.

Workflow

  1. Load a source video.
  2. Use the range slider to select the portion to process (Begin/End handles).
  3. Set the number of Subdivisions (how many chunks to split into).
  4. Choose Gapfill Duration (1s, 2s, or 3s per transition).
  5. Click Chunk Clip — the gapfill queue appears showing Frame A → Frame B pairs.
  6. Click Begin Longshot Render — the model generates each gapfill transition.
  7. When all renders complete, click Assemble Final Video.
  8. Click Accept Edits to stitch the result back into the original source.

Settings

10. Trim

Trim videos to a specific time range using FFmpeg. Lossless — no re-encoding.

Workflow

  1. Load a source video.
  2. Drag the Begin and End handles on the range slider.
  3. Thumbnails update to show the begin/end frames.
  4. Click Trim Video.
  5. Result plays in the right preview. Save to project with a custom name.

11. Crop

Crop videos to a specific region using FFmpeg.

Workflow

  1. Load a source video.
  2. Click Grab Frame to capture the current playhead position.
  3. A crop rectangle (cyan dashed outline) appears on the frame preview.
  4. Drag the rectangle to position it. Choose a Crop Size Preset or resize manually.
  5. Click Crop Video.

Crop Size Presets

512x512, 640x480, 720x480, 768x512, 832x480, 480x720, 512x768, 480x832, 1024x576, 576x1024, 1280x720, 720x1280

StillGrabber

Extract evenly-spaced still frames from video clips.

  • Source Video — Drop or load a video file. The player shows the source with full scrubbing controls.
  • Frame Count — Number of frames to extract, evenly distributed across the clip duration.
  • Output Resolution — Choose from source resolution or preset sizes. Extracted frames are saved as PNG.
  • Right-click send-to — Right-click any extracted frame to send it to Img2Vid, image generation tabs, face swap, or any other image destination.

Video LoRA

Train custom video LoRAs and generate videos with them.

  • Training — Uses ai-toolkit backend for video LoRA training. Configure dataset, training parameters, rank, learning rate, and training steps.
  • Batch Generation — Generate multiple videos using a trained video LoRA with full parameter control.
  • Character Dataset Builder — Build training datasets from existing clips with metadata tagging.

Color Correct

Dedicated color correction tab with reference-based matching, per-category controls, and batch processing.

Setting a Reference

  • Right-click any image or video anywhere in the app → "Set as Color Reference" to define the target look. The Color Correct tab opens automatically with the reference loaded.
  • Or click Load... in the Reference section to pick a file.
  • The reference frame thumbnail shows what you're matching to.

Adding Sources

  • Use Send to → Color Correct (source) from any right-click menu to send files for correction.
  • Or click Load... / Add to pick files. Drag-and-drop also works on the batch file list.
  • The Source video player shows the first file loaded, with full playback controls.

24. AI Assistant (Qwen Chat)

Click the AI button in the header bar to open the Qwen Assistant — a floating chat window powered by Qwen 3.5 4B (BF16). Ask questions about the application's features, workflows, settings, troubleshooting, or any of the upstream technologies it integrates.

Features

  • Context-aware answers — The assistant has a built-in reference covering all app tabs, workflows, settings, and common issues. When your question mentions a specific technology (ControlNet, LoRA, FLUX, etc.), relevant upstream documentation is automatically injected into the conversation context.
  • Per-project chat history — Conversations are saved per project and persist across sessions. Switching projects switches the chat history.
  • Multi-turn conversation — The assistant remembers previous messages in the current session (up to ~12K tokens of context).
  • VRAM-aware lifecycle — Qwen loads on your GPU when the chat opens (~5 GB VRAM). Starting any generation pipeline automatically unloads Qwen and disables the chat input. Closing the chat window also unloads the model.

Usage

  1. Click the AI button in the header bar (next to the ? help button).
  2. Wait for the model to load (first time may take a moment to download ~5 GB).
  3. Type your question and press Enter to send (Shift+Enter for newline).
  4. Click Clear History to start a fresh conversation.
  5. Click Close or the window close button to unload the model and free VRAM.

Limitations

  • The assistant is information-only — it cannot modify files, run code, change settings, or access the internet.
  • It runs a 4B parameter model locally, so answers may not always be perfectly accurate. Verify critical information.
  • While the chat is open, Qwen occupies ~5 GB VRAM. Close the chat before generating to reclaim this memory.
